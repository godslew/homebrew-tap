# homebrew-tap

Homebrew tap for [gclip-cli](https://github.com/godslew/gclip-cli) - A CLI tool to collect, search, and insert frequently used shell commands.

## Installation

```bash
brew tap godslew/tap
brew install gclip-cli
```

## Available Formulas

- **gclip-cli** - Collect, search, and insert frequently used shell commands (macOS only)

## Update

```bash
brew upgrade gclip-cli
```

## Uninstall

```bash
brew uninstall gclip-cli
brew untap godslew/tap
```
